# Java Key-Value Store

A Java-based in-memory key–value store exposed over HTTP, built from scratch to explore backend and distributed systems fundamentals.

## Current Features
- HTTP server (no framework)
- Thread-safe in-memory KV store
- Explicit thread pool for concurrency control
- Clean separation of concerns
- Graceful shutdown

## Roadmap
- Multi-node cluster
- Key partitioning
- Replication
- Eventual consistency
- Failure handling
